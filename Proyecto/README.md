# Proyecto ADS
Esta carpeta en el repositorio **ADS** tiene la finalidad de trabajar en los diferentes elementos referentes al proyecto, de tal manera que tengamos un buen manejo del control de versionamiento, haciendo que se pueda trabajar de manera remóta y dinámica sin afectar la calidad del trabajo.

---

## Casos de uso
Se usarán los elementos que se presenten como más fundamentales al momento de hacer la definición de los **requisitos funcionales** tal que puedan ser usados como base del sistema, permitiendo que mostremos los elementos necesario para el funcionamiento del sistema.

1. Registrar cliente y cuenta de ahorros.
2. Registrar aporte mensual.
3. Realizar sorteo semestral de viviendas.
4. Consultar el estado de cuenta y progreso.
5. El sistema debe generar reporte de clientes en mora.

Para hacer la visualización de diagrama observar los archivos con extención `.vpp`.
